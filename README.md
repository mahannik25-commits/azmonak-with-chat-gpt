# آزمونک 

سایت آزمون آنلاین درس‌ها با سوالات چهارگزینه‌ای و نمره‌دهی از ۲۰.

## درس‌ها
قرآن، عربی، ریاضی، علوم، فارسی، مطالعات، انگلیسی

## نحوه استفاده
۱. فایل index.html را باز کنید یا از GitHub Pages استفاده کنید.
۲. درس را انتخاب کنید، ۱۰ سوال چهارگزینه‌ای جواب بدهید.
۳. در پایان نمره از ۲۰ نمایش داده می‌شود.

## فعال‌سازی GitHub Pages
Settings ← Pages ← Source: Deploy from a branch ← main / (root)
